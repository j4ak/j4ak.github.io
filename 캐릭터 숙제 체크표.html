⚠ 데이터 파일 연결이 필요해요
미완료완료진행중 (우클릭)해당 없음
칸을 누르면 미완료와 완료가 바뀝니다. 초기화는 위의 초기화 버튼으로 직접 합니다. 편집 모드에서는 캐릭터·항목·분류 이름을 직접 고치고, ≡ 손잡이를 끌어 캐릭터 순서와 일일·주간·월간·시즌 항목 순서를 바꾸고, ━ 버튼으로 캐릭터 아래에 굵은 줄을 넣고 빼며, 대분류의 ＋로 항목을 추가하고 항목 아래의 삭제·숨김 버튼으로 항목을 지우거나 감출 수 있습니다(숨긴 항목은 집계에서도 빠집니다). 진행중은 편집 모드에서 항목의 '진행'을 켠 뒤 칸을 우클릭하면 표시되고, 진행중 칸을 클릭하면 완료가 됩니다(집계에서는 미완료와 같게 셉니다). 일일 숙제를 모두 마치면 캐릭터 이름 칸이 녹색으로 바뀌고, 이벤트, 쿠폰, 제전은 진행바에 반영되지 않습니다. 데이터 파일을 연결해야 수정할 수 있고, 변경 내용은 연결한 JSON 파일에 자동으로 저장됩니다(이 브라우저에도 함께 저장됩니다).
